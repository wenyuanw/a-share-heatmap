热力图不只能自己看，也能给别人看。如果你的财经站点缺一块市场全景、博客想在盘后配一张图、或者你想给自己搭一个私人看盘页，有两条路：一段 iframe 嵌入，或者把整个项目部署到你自己的域名。

## 方式一：一段 iframe，三分钟上线

把下面的代码粘进页面，宽高按布局调整：

```html
<iframe
  src="https://dapan.app/?market=all&borders=off"
  width="100%"
  height="560"
  style="border:0;border-radius:12px"
  loading="lazy"
  title="A 股市场热力图">
</iframe>
```

几个要点：

- 建议 `loading="lazy"`：访问者滚动到热力图时才加载行情，不影响你页面的打开速度。
- 嵌入场景推荐 `?borders=off`，去掉实线边框，色块更干净。
- 缩放、拖拽、悬浮查个股这些交互在 iframe 里完整可用，和主站体验一致。
- 最小可用宽度约 360px（移动端布局），高度不低于 480px，热力图会自动适应容器。

`src` 里的查询参数可以直接指定初始状态：`market` 选市场范围，`period` 选当日 / 近 5 日 / 近 20 日 / 今年以来。比如给加密货币读者换不了口味，但给创业板读者挂一张「近 20 日创业板」很合适：`?market=cyb&period=month`。完整参数表见[嵌入指南](/embed)。

## 方式二：自部署，一分钟拥有自己的版本

项目开源（MIT 协议），基于 Next.js 构建，无需数据库、无需环境变量。点 [一键部署到 Vercel](https://vercel.com/new/clone?repository-url=https://github.com/wenyuanw/a-share-heatmap)，授权后自动创建项目开始构建；或者本地跑起来：

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # 生产构建
pnpm start      # 运行生产构建
```

部署到你自己的域名，就是你的私人看盘工具。数据端内置了每日股票名册自动刷新和多级行情兜底，日常零维护；所有用户偏好（自选、配色、快捷键）都保存在访问者本地浏览器。部署细节和行情数据说明见[自部署指南](/self-host)。

## 怎么选

| 场景 | 建议 |
| --- | --- |
| 博客、看板、财经站点补一块行情图 | iframe 嵌入，三分钟搞定，行情始终跟随官方站点 |
| 定制功能、私有域名、不想依赖第三方 | 自部署，代码随便改 |
| 只是个人看盘 | 不折腾，直接收藏 dapan.app |

两种方式都免费。个人与非商业站点随意使用，如果方便，在热力图附近留一个指向 dapan.app 的链接就是最好的支持。

行情数据仅供研究参考，不构成投资建议。
